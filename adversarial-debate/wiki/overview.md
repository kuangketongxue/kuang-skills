# 认知宪法总纲

这份文档不是资料库，是用户本人的**认知宪法**。辩论必须严格锚定在它之内——
用用户已认可的知识体系去审查用户的决策，不许模型用外来知识干扰。

## 三类笔记（权重从高到低）

| 层级 | 形态 | 权重 |
|---|---|---|
| ① 实践笔记 | `【编号】狂客同学读书挑战。【《书名》】。[日期+日期]。实践：【...】` | **最高**——用户亲手验证过的结论 |
| ② 长文原声 | `## 【编号】标题：` 后接 2000~4000 字长文 | 高——用户原创判断，论证链最完整 |
| ③ 书籍摘录 | `## **【P页码】标题**`、读书章节列表（《上行》《指数基金定投指南》《让时间慢慢陪你变富》《穷爸爸富爸爸》《AI时代，成为强者》《乔布斯传》） | 中——他人著作，用户在读但非原创 |

**引用时不得把三者当同级证据。** 书籍摘录（③）不能用来否定用户自己的实践笔记（①）。

## 编号体系

- `【MMDD】`（1009–1231、0101–0123）：早期长文
- `【YYYY.M.DD】`（2025.5.x – 2026.9.x）：2026 系列，最新、最密集、单条较短，常一条含 2 个子话题（子标题用 `### 话题:`）
- `【P页码】`（P123~125 这种区间形态）：书籍摘录

## 出处格式（强制）

```
[出处：【笔记编号】<标题>]
```

例：`[出处：【1028】赚钱能力是养出来的]`｜`[出处：《请辩》[2025.9.25+10.29] 实践]`｜`[出处：《上行》P140~149]`

**编号复用时必须带标题**：【1013】有早期长文和《请辩》实践笔记两条；【1113】有两条不同笔记
（Circle 抄底 / 持有现金=做空资产）。只写编号不写标题 = 出处无效。

## 已知缺陷（引用时必须处理）

- **重复段**：【2026.3.6~3.20】整段重复 2 次；【2026.4.27】+【2026.4.28】连排重复；【2026.6.17】重复 2 次。
  `fetch_kb.py` 会自动剔除完全相同的块并在报告里列出。
  **绝不能把重复的两条当两个独立论据来加强论证。**
- **图占位符**：`![][image39]` 是 markdown 导出残留，无内容。`fetch_kb.py` 已自动删除（本次 56 个）。
- **转义波浪号**：`\~` 是 `~` 的转义（如【1032】~【1033】、【P137\~139】），引用时还原成 `~`。
- **尾部空笔记**：【2026.9.7】、【2026.9.9】、【2025.3.24】只有标题无正文，不可引。
- **编号复用**：见上方出处格式条。
