# Image Generation

## 概述

通过Sensenova API根据文本提示词生成图片。支持多种艺术风格、主题色彩和内容类型，可用于辅助前端设计、概念原型、信息图等场景。

## 必备先决条件

- 必须先读 `~/.claude/.secrets/qweather_key.enc` 中的 `SENSENOVA_API_KEY`（DPAPI解密后的值）
- API端点：`https://token.sensenova.cn/v1/images/generations`
- 默认模型：`sensenova-u1-fast`（快速模式）

## 基本用法

```bash
# 生成单张图片
npx -y curl-command \
  -H "Authorization: Bearer $SENSENOVA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "sensenova-u1-fast",
    "prompt": "你的提示词",
    "size": "1024x1024"
  }'
```

## 提示词结构

一个完整的提示词包含以下元素：

1. **主色调** - 主色（如：柔和的粉色、淡黄色、浅蓝色）
2. **艺术风格** - 如：可爱卡通风格、写实、插画、素描等
3. **内容元素** - 具体的图像内容（如：猫咪、拟人化表情、物体）
4. **版式结构** - 页面布局信息（区块、排版）
5. **核心文字** - 图片中需要包含的关键文字

## 风格预设

| 风格 | 描述 | 适用场景 |
|------|------|----------|
| `cute-cartoon` | 极具亲和力的可爱卡通风格，包含猫咪、拟人化表情 | 个人项目、生活应用、亲子内容 |
| `minimalist` | 极简风格，线条干净，留白充足 | 企业官网、技术文档、作品集 |
| `data-viz` | 数据可视化风格，图表明了，重点突出 | 报表、分析仪表盘、统计展示 |
| `realistic` | 写真级逼真风格，细节丰富 | 产品展示、真实场景再现 |
| `retro` | 复古风格，胶片质感、暖色调 | 生活方式、怀旧类内容 |

## 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `model` | string | `sensenova-u1-fast` | 可选：`sensenova-u1-fast`（快速）或 `sensenova-u1-quality`（高质量） |
| `prompt` | string | 必填 | 图片生成提示词 |
| `size` | string | `1024x1024` | 图片尺寸，如：`1024x1024`、`2752x1536`、`512x512` 等 |
| `n` | number | `1` | 生成图片数量，1-4 |

## 故障排除

- **Token 失效**：检查 `~/.claude/.secrets/qweather_key.enc` 是否包含有效的 `SENSENOVA_API_KEY`，或用以下命令刷新：
  
  ```bash
  powershell -NoProfile -Command "'<新值>' | ConvertTo-SecureString -AsPlainText -Force | ConvertFrom-SecureString | Out-File 'C:\Users\kuang\.claude\.secrets\qweather_key.enc' -Force"
  ```
  
- **API 超时**：默认使用 `sensenova-u1-fast` 模型，若长时间无响应请切换至质量模型或重试
  
- **图片质量不满意**：调整提示词中的主色调、艺术风格描述或内容元素，重新生成

## 最佳实践

1. **颜色先行**：在提示词中明确主色调，确保生成的图片与项目配色一致
2. **风格锚定**：为不同用途选择对应的风格预设，避免风格模糊
3. **内容具体**：提示词中包含具体的内容元素而非抽象描述，生成结果更可控
4. **尺寸匹配**：根据使用场景选择合适的图片尺寸，避免后期裁剪失真
5. **循序渐进**：首次使用建议生成小尺寸预览，确认无误后再生成高分辨率版本
