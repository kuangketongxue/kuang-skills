## About

Proactive Agent Mail readiness check skill for WorkBuddy — checks whether the mail channel is ready before the agent sends proactive notifications.

## Install

Copy `SKILL.md` into your agent's skills directory:

```bash
cp SKILL.md ~/.claude/skills/agent-qq-auto/SKILL.md
```
